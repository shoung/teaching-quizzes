## 2. 產品定位與範圍

### 一句話體驗

「你有一間還不出名的巴黎沙龍、一筆有限預算，以及一本來自未來的經營手帳。你能在四幕故事中，讓一場藝術之夜既有人來、有人談論，也有人願意再次參加嗎？」

遊戲重點是把課本概念轉成有證據、有成本、有後果的選擇。學生要辨認需求、安排資源、閱讀資料並回應人的衝突，不能只靠背縮寫或每次選最昂貴的宣傳。

### 玩法方案比較

| 方案 | 適合之處 | 代價 |
| --- | --- | --- |
| A 純情境問答 | 容易沿用現有答題元件、閱讀直接 | 移動與扮演感弱，經營結果較像答題裝飾 |
| B 2D 移動＋決策卡牌，建議採用 | 移動用於找人與證據，卡牌呈現取捨，能控制課堂節奏 | 需專屬場景與可重算的遊戲狀態 |
| C 自由經營＋隨機牌組 | 重玩變化多，較接近長時間經營遊戲 | 隨機性、平衡與操作學習增加，難確保每位學生接觸同樣的課程內容 |

本 PRD 以 B 展開，仍待使用者核准。卡牌是有情境與成本的行動選項，不是抽卡、集卡或牌庫構築。首版採固定事件與確定性結果，讓不同選擇可以公平比較。

### 首版包含

- 一條完整主線、四幕、十二道決策；同一組場景依籌備與活動階段變化。
- 六位 NPC、可重讀的訪談／資料、名詞手帳、經營指標與差異結局。
- 滑鼠、觸控與鍵盤的等價操作；不依賴精準移動才能答題。
- 本機續玩、上一頁、重玩、分享、前端結果與教師討論提綱。

### 首版不包含

多人、帳號、後端、排行榜、真實廣告投放、即時生成式 AI、外部 CRM、自由建築、戀愛養成、戰鬥、抽卡付費、多章世界、歷史人物配音或歷史事件完整模擬。不引入真實營收預測或宣稱本測驗能認定學生的職場能力。

## 3. 世界觀與故事

### 年代與虛構界線

美好年代屬 19 世紀末至 1914 年前的歷史語境，並非 18 世紀；本案採約 1900 年，不混用啟蒙時期沙龍與美好年代的服飾、媒體及城市設備。[法國公共文化平台 Histoire par l’image](https://histoire-image.org/mots-cles/belle-epoque)與 [BnF《Paris Belle Époque》書目](https://catalogue.bnf.fr/ark%3A/12148/cb36172442b)作為年代查核來源。

「2026 經營手帳」是明示的架空設定。現代方法出現在手帳與教學提示中；故事內仍使用邀請函、回函、海報、報刊、人際引薦與現場接待。AI 助手為預先撰寫的未來工具模擬，不連接 API，不把數位廣告、社群平台或手機描寫成 1900 年已有的技術。

沙龍是由女主人組織的私人藝術交流聚會，不混同官方美術展覽 Salon，也不直接套成售票夜店。首版以自有經費與合作支持舉辦，預算不是營收、來賓也不直接等同付費顧客。

### 故事弧線

克萊兒夫人希望把一間缺乏特色的沙龍，變成新銳藝術家、讀者與文化愛好者願意交流的地方。她收到一份有贊助機會的藝術之夜邀約，但手上的經費、接待能力與人脈都有限。

玩家先理解「誰會來、為什麼要來」，再決定怎麼宣傳與配置預算；接著處理未經證實的名人背書、名單資料與人手分工；最後面對活動當晚的人潮、衝突和合作方要求，完成有依據的後續提案。

女主人具備主動策劃、談判與管理的角色，不以婚姻、外貌或討好權勢作為成功判準。角色需求依訪談資料呈現，不把階級、性別或年齡當成必然偏好。

### 場景與人物

| 場景 | 主要用途 | 可互動物件 |
| --- | --- | --- |
| 自家沙龍 | 品牌體驗、藝術交流、最終活動 | 入口、展示牆、交談區、座位圖 |
| 書房 | 目標、預算、資料與手帳 | 書桌、回函簿、預算帳冊、未來手帳 |
| 街角印刷店 | 邀請函、海報與版本測試 | 印刷樣稿、報價、測試回函 |
| 藝文咖啡館 | 受眾訪談、引薦及合作 | 談話桌、報刊、合作提案 |

四處皆為小型單畫面場景，以明確出口或目的地清單切換，不做城市大地圖。藝術之夜開始後依序觸發主線，不能因離開場景逃過決策。

六位原創 NPC：沙龍管家、新銳畫家、藝文寫作者、潛在贊助人、常客代表、印刷店經營者。每位有需求與限制；NPC 不以「正確答案老師」的口吻提示唯一選項。

## 5. 四幕十二道決策

每幕三題，固定順序。每次只顯示一道主決策，採三至四張單選行動卡；題目、證據、選項、回饋構成完整教學單位。下表定義內容方向，完整逐選項分數與資源效果在功能階段開工時建立並驗證。

| 題／幕 | 情境與證據 | 玩家要處理的問題 | 教學重點與後果 |
| --- | --- | --- | --- |
| 1 第一幕：一間無人知曉的沙龍 | 三組訪談顯示：創作者想要交流回饋、收藏愛好者需要作品脈絡、一般來賓重視輕鬆理解 | 選擇首場主受眾，依需求而非身分刻板印象分群 | 不同選擇開出不同敘事與相符宣傳機會；可有多個合理答案 |
| 2 第一幕 | 周邊聚會已各有定位；現有邀請函只寫「最盛大的夜晚」 | 決定可交付的主題、價值主張與體驗 | 主題是策略承諾，不能只選喜歡的顏色或誇大規模 |
| 3 第一幕 | 容量 36 人、經費 100 點、尚無穩定名聲 | 設定知名度與出席目標，兼顧信任及服務能力 | 人多與出名為主要目標，接待與信任是成功護欄；本題不改變全班共用通關門檻 |
| 4 第二幕：讓巴黎開始談論你 | 小眾藝文寫作者讀者少但需求吻合；大型報刊觸及廣但費用高；熟客可親自引薦 | 挑選可負擔、符合定位的傳播合作 | 沒有所有情境都最好的渠道；付費背書需說明合作關係 |
| 5 第二幕 | 兩批各 100 封邀請函，甲收到 20 份有效回函、乙收到 12 份；名單與寄送時間可比 | 判讀測試，決定是否及如何擴大 | 20% 與 12% 是本次回函率，不是實際出席率；結果尚不能保證未來成效或宣稱統計顯著 |
| 6 第二幕 | 已使用經費、剩餘報價及接待缺口均可查；宣傳與現場準備競用資源 | 在追加宣傳、改善接待、保留備用金間取捨 | 以當前狀態與機會成本決策，不是越花錢越高分 |
| 7 第三幕：名聲背後的工作 | 未來手帳草稿稱「名畫家已答應出席」，原始信件僅寫「有機會再議」 | 審核 AI 邀請文案與未證實承諾 | 查來源、確認授權、改寫後由人核准；短期聲量不能抵銷信任損害 |
| 8 第三幕 | 回函簿有重複姓名、未確認回覆與一人攜伴；提供匿名範例資料 | 清理並核對人數，再判斷是否加邀 | 區分原始回函、有效確認與攜伴，不重複計人；不要求輸入真實個資 |
| 9 第三幕 | 入口與作品導覽共用兩位助手，場地容量不變 | 分工、設負責人與應變步驟 | 用責任與交接改善接待；不能用無限加班或超額收客解決 |
| 10 第四幕：藝術之夜與下一封邀請 | 到場者與未到者需求不同；有人願意接收下一次邀請，有人沒有同意 | 選擇分群回訪與轉介紹方式 | 以意願與需求維繫關係；回訪不能回頭增加本次已到場人數 |
| 11 第四幕 | 贊助人要求臨時插入長篇宣傳，與原定創作交流衝突，現場已有等待 | 協調贊助需求、來賓承諾與流程 | 談替代安排、透明說明並守住承諾；非一味迎合或粗暴拒絕 |
| 12 第四幕 | 手帳自動產生「下次必定爆滿」結案；有本次渠道、回函與到場資料 | 選擇有事實、限制與下一步的經營提案 | 校正 AI 結論，不把相關當因果；將方法遷移至現代品牌活動 |

### 出題規則

- 各題至少有兩個可負擔方案，其中至少一個零成本；資源不足不會造成無法作答。
- 前期受眾與定位會影響後續建議及部分效果；同一方案可以在不同策略下有不同合理性。
- 判斷所需資料必須在選擇前可取得；不以未告知的隱藏條件事後扣分。
- 避免正確選項永遠最長、永遠第二張，或錯誤選項明顯荒謬。
- 每張卡提供行動、承諾成本與理由摘要；選中後再確認，不能一點即扣款。
- 主觀美術喜好不列入十二道計分題；未來若增加此類題須標為 `reflection`，只記錄感受。
- 所有路線均能完成並看結果，不必答對才能繼續。低分造成可理解的後果與補救建議，不羞辱學生。

## 6. 核心循環與操作流程

入口與操作說明 → 當前幕場景 → 走近人物／點選目的地 → 閱讀對話及證據 → 開啟一題決策卡 → 選擇 → 確認，下一頁 → 資源與人物回饋 → 下一題。第十二題以「確認，查看結果」結束。

### 移動與互動

- 桌面以方向鍵或 WASD 移動、E 互動；同時提供點選目的地與「前往目前任務」按鈕。
- 手機以點選目的地及大尺寸互動按鈕為主，不強制使用虛擬搖桿、不強制橫向。
- 任務清單提供「與誰交談／閱讀哪份資料」的直接操作。學生可不操控角色步行而完成全部教學內容。
- 走路只增加情境感，不耗經費、不扣分、不要求反應速度。沒有真實時間倒數。
- 對話、手帳或決策面板開啟時暫停場景快捷鍵；沒有背景限時事件。
- 已讀關鍵資料可重開。選擇前的預期效果只說方向與已知成本，不顯示教學分數或尚未觀察的精確人數。

### 一頁一題、上一頁與改選

- 當前路由與一道主決策對應；對話、證據與場景是同一道題的準備，不同時出現多題。
- 未選擇不能前進；未提交的選擇可取消或更換。已知成本不足的卡有文字說明，不能只靠灰色表達。
- 提供「上一頁」，保留已填答案。返回閱讀而未改選，不影響任何進度或數值。
- 若確認改選先前已提交的題目，先說明「後續事件將重新推演」；確認後清除該題之後的答案與衍生狀態，從初始值依保留的選擇重算。
- 不使用加分後再扣回的方式處理回看；相同選擇只能產生一次效果。重新確認未更改的答案也不能重複取得資源。
- 結果頁提供逐題閱讀，修改決策則需回到該題並依上述流程處理；重玩重新開始。

## 7. 經營系統與成果

### 狀態提案

| 狀態 | 初始值與範圍 | 用途 |
| --- | --- | --- |
| 經費 B | 100 點，0–100，整數 | 抽象教學資源，不冒充歷史法郎價格；首版無借貸、無收入補款 |
| 知名度 A | 10／100，0–100，整數 | 目標圈層認識沙龍的遊戲指數，不是巴黎人口實際調查百分比 |
| 信任 T | 50／100，0–100，整數 | 宣傳可信、承諾履行與尊重來賓的綜合遊戲指數 |
| 接待準備 Q | 40／100，0–100，整數 | 人手、動線及交接準備，與宣傳效果分開 |
| 有效確認 R | 0 人，0–36 | 經核對且有座位的確認人數；額滿後只加入候補，不超賣 |
| 候補名單 W | 0 人起，整數 | 只供需求與後續邀請分析，首版不自動遞補成當晚出席 |

頂部優先顯示經費、知名度與目前任務；信任、接待及確認／候補人數放在可開啟的經營帳冊。關鍵變動以文字通知，不能只用動畫或顏色傳達。

經費在確認選擇時扣除且不得低於零。A、T、Q 的變動限制在 0–100，R 不超過容量；每個選項有明確效果資料。劇情呈現使用前後差值，避免被邊界截斷後顯示錯誤增量。

### 人潮與知名度分開計算

前九題完成後鎖定本次活動的有效確認與準備狀態，計算基準到場人數：

`基準到場 = floor(R × (0.50 + 0.25 × T / 100 + 0.25 × Q / 100))`

這是方便教學與重算的**遊戲規則**，不是學術估計式或真實活動預測。R 最多 36，因此到場人數永不超出場地容量。知名度不直接代入到場公式；宣傳方案須依受眾契合影響有效確認，讓學生看出「被知道」與「願意來」不同。

第四幕使用此基準人數作當晚資料。第十題只影響後續關係及信任，第十一題處理現場體驗，第十二題形成結案建議；三題均不能回頭增減本次已到場人數。結果另列活動結束時的知名度與信任，不以最後的 T 值重算先前到場資料。

### 成功門檻與結局

首版提案的「人潮與名聲兼得」須同時達成：到場至少 28／36 人、最終知名度至少 70、最終信任至少 60、開場前接待準備至少 60，且無超支。門檻在開場與結果清楚展示。Q 與 T 是服務護欄，不能靠大量曝光抵銷。

結局依序判定，互不矛盾：

1. **人潮與名聲兼得**：全部條件達成。
2. **熱鬧之後的考驗**：人潮與知名度達標，但信任或接待未達護欄。
3. **值得再來的小沙龍**：人潮或知名度未達標，但信任與接待達標。
4. **下一場的起點**：其餘組合，指出兩個優先改進原因。

每個結局都能查看完整結果。上述初始值、公式與門檻須經平衡試算與學生試玩再定版；本 PRD 沒有宣稱目前已證明可達成。正式開發驗收必須找到至少兩條不同、未超支且能達成完整成功的策略，並證明高聲量低信任路線不會得到完整成功。

## 8. 教學分數與回饋

經營成果描述這次故事發生什麼；教學參考分數描述選擇是否使用了題目提供的關鍵原則，兩者分開呈現。不能直接拿知名度、到場人數或剩餘經費當作學生能力分數。

- 十二題每題 0–3 分，總滿分 36，顯示 `round(實得分 ÷ 36 × 100)`。
- 3 分：依證據處理關鍵條件與限制；2 分：方向合理但遺漏一個重要條件；1 分：只處理表面或單一指標；0 分：與已知證據相反或違反明示承諾。
- 每個選項對照當時狀態有明確評分依據；不因單純選擇不同受眾而扣分，多個方案可以同為 3 分。
- 「答對題數」旁標示「達完整教學參考標準」，計入得 3 分的題數；不宣稱每個商業情境只有唯一正解。
- 六面向各兩題、滿分各 6；各自換算百分制，提供雷達圖與可重排文字表。不把面向分數當成常模、職涯診斷或真實工作績效。
- 可選的結果反思不計分、不影響結局；無主觀面向的偽造能力分數。

### 一道題的回饋範例

第 5 題：「甲收到 20／100 份有效回函、乙收到 12／100 份。」完整參考處理是暫以甲作為下一步測試方向，同時確認名單、寄送條件與後續到場表現；不能直接宣稱甲一定帶來 20 位賓客。即時回饋先說明選擇造成的情境與可觀察變化；逐選項分數、完整理由與其他合理方案在結果頁揭示。

### 結果內容

1. 沙龍活動畫面與結局；到場／容量、知名度、信任、接待、剩餘經費，逐項顯示是否達標。
2. 教學參考分數、完整符合題數、計分規則、六面向雷達圖與分數表。
3. 十二題的情境、當時證據、玩家選擇、成本與後果、評分理由、替代思路。
4. 兩項優先練習，由最低面向選出；同分依第 4 節面向順序取前兩項，避免任意變動。
5. 現代遷移練習：把同一套方法用在校園展覽或品牌快閃活動，回答「受眾、指標、資源、驗證」四個問題；此為自我反思，不作自動評分。
6. 重新經營、分享遊戲及列印友善閱讀；不要求登入、個資或付費。

## 11. 響應式、可及性與效能

- 以 WCAG 2.2 AA 為基準；全部主要操作可用鍵盤及觸控完成，拖曳卡牌非必要操作。
- 內文至少 `1.125rem`、可見小字至少 `1rem`，使用相對字級；此為本專案字級規則，不稱為 WCAG 硬性最小字號。
- 一般文字對比至少 4.5:1，大字及必要控制圖形依準則至少 3:1；裝飾美術不能降低文字可讀性。
- 檢查 320px 重排、200% 文字放大與文字間距覆寫；選項、成本、確認及上一頁均不得被遮蔽。操作目標以至少 44×44 CSS px 為設計目標。
- 提供清楚的焦點、標籤、單選群組與狀態訊息；換題焦點移至可見題目。對話框需管理焦點、關閉回復與背景不可操作，避免巢狀模態。

## 13. 驗收清單

### 教學與遊戲

- 十二題各具情境、至少兩個選項、證據與解析，六面向各兩題；沒有把審美偏好當正解。
- 每個概念至少有一次情境應用與結果回顧；名詞解釋不是額外通關障礙。
- 知名度、有效確認與到場分開；能出現「廣為人知但參與不足」與「小眾但體驗良好」。
- 資源不為負、確認與到場不超容量、低預算永遠有可選方案；候補不被計入當晚人數。
- 至少兩條不同成功策略、至少一條高曝光但信任受損路線；相同選擇歷史得到相同結果。
- 正式選項效果表與自訂通關門檻一起校對；教學分數不直接由經營成果換算。

### 流程與資料

- 未作答不得前進；按上一頁保留答案；只閱讀不重算，確認改選才清除後續並重演。
- 連點確認、回看、重載與重複提交不重複扣款或加分。
- 十二題完成後立即查看結果；直接開啟結果或未來題不能跳過作答。
- 重玩只清除此遊戲；版本不相容、損壞內容、非法選項及不可負擔歷史有安全處理。
- 禁用 localStorage 仍可完成；雜湊路由重新整理與 GitHub Pages 子路徑正常。
- 短網址的實際導向及 QR 圖片解碼正確，分享目標固定第一題。
- 子頁各位置無目錄／首頁連結，沒有登入、後端依賴或個資收集。

### 可及性與試玩

- 桌面、平板、手機可完成；鍵盤可完成全部主線，地圖提供等價任務操作。
- 文字對比、焦點、對話框、狀態朗讀、字級、200% 放大、320px 及文字間距通過檢查；修正後重新掃描與鍵盤驗證。
- 能在停用動態、無音效及場景圖失敗的條件下作答；圖表有文字等價內容。
- 至少五位目標學生首次試玩，目標至少四位不需人員代操作即可完成；以完成者中位數 25–30 分鐘為內容節奏目標，記錄個別範圍，不把時長變成失敗倒數。
- 課後討論要求學生解釋一項「曝光不等於參與」及一項「成長需要服務能力」的取捨；此為教學觀察，不宣稱已有學習成效實證。
- 提交或部署前執行 `npm test`、`npm run build`；規則測試涵蓋計分、條件選項、重演、儲存與邊界。發布依實際 Actions／公開站證據回報。

## 14. 主要風險與處理

| 風險 | 處理方式 |
| --- | --- |
| 題目換皮、缺少遊戲感 | 場景提供人物需求與資料，決策影響後續對話、邀請與現場；不是走路後顯示無關考題 |
| 經營太複雜、課堂玩不完 | 單章、固定十二題、小地圖、直接前往、無反應速度關卡；以首次試玩調整閱讀量 |
| 每題都存在顯而易見的「最貴最好」 | 設定成本、契合與信任取捨，驗證不同成功策略；正解依可見資料而定 |
| 高分卻經營未成功讓學生困惑 | 分開解釋知識應用與資源協調；逐題呈現後果，明說分數與通關規則為課堂自訂 |
| 回看使經費及劇情矛盾 | 以選擇歷史作唯一來源，變更前題清除後續並從初始值重算 |
| AI 與歷史混淆 | 開場明示未來手帳為架空工具；現代術語與當代宣傳手段分層敘述 |
| 美好年代被描述成所有人的美好生活 | 保留資源、發聲與社交門檻的差異，不美化排斥；遊戲不宣稱代表完整歷史社會 |
| 2D 地圖阻礙閱讀與操作 | 場景外的語意化任務清單、直接互動、可減少動態與手機重排從介面階段驗收 |

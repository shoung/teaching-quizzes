# 行銷人的一天：第二章對白修訂

日期：2026-11-08｜案例版本：7｜範圍僅限行銷遊戲第二章。

## 修訂方向

原稿把不少研究方法、評分提醒和未知資料的說明放進客戶嘴裡，對白偏短，且顧客樣貌缺乏可想像的人物。本輪讓林老闆以大學附近健身房的負責人身分說明經營困擾，教學解釋留在名詞圖鑑與結算解析。

- 品牌改為「轉角健身房」，使用「月卡／年卡」等台灣常用說法。
- 每輪六段開場，追問補充具體例子與流程，維持一次只呈現當下對白；長回答可分段。
- 顧客樣貌以自願分享的「小安，22歲、大學生、有兼職、空檔不固定」作為代表情境。已來店詢問、尚未正式體驗，不假裝所有新客都一樣。
- 開場、追問與整理標題都清楚指出要選痛點、顧客樣貌、旅程痛點與機會、主方案與理由、服務分工。
- 卡片內容和解釋逐項對回對白，保持原題目ID、選取規則與計分。
- 仍為一位客戶、五輪、每輪最多五次追問；角色走動、中央視窗、音訊、自由選章及無登入／無存檔皆維持。

## 圖鑑按鈕修正

第二章圖鑑未選取按鈕原本沒有背景色設定，瀏覽器顯示淺灰底，文字卻繼承淺色，造成反白難辨識。本輪明訂未選取深色底、淺色字與清楚邊線；選取後才使用金色字與邊線，保留可見鍵盤焦點。

Ego Lite 實測：未選背景 rgb(26,45,53)、文字 rgb(237,240,233)；選取背景 rgb(32,52,60)、文字 rgb(237,203,129)。以Tab／Enter從第一個名詞切換第二個，只有第二個 aria-pressed=true，第一個恢復未選深色。

## 驗證

- 對白總字元由2,457增至5,445（開場＋全部追問回答），約為原本2.2倍；一次仍只呈現當下的一段。實際完成時間仍待學生試玩校正。
- 行銷相關測試11檔、69項通過；完整 `npm test` 35檔、203項通過；`npm run build` 通過。Vite仍有Three.js分包超過500kB的提示。
- 實際走完五輪，參考正確選項得到100分、24項命中，結算顯示「林老闆｜轉角健身房」。開場、追問、整理皆顯示當輪選擇目標。
- 第一輪問滿五次後八個追問均停用；長回答換段呈現並移動閱讀焦點，原本追問及提交規則不變。
- 圖鑑未選文字對比12.40:1、選取文字8.32:1；滑鼠與Tab／Enter切換狀態均正常。
- 320px、根字級200%與文字間距覆寫後，圖鑑彈窗clientWidth/scrollWidth均286px、名詞清單均222px，選取服務藍圖長名詞後仍無橫向溢出；axe WCAG 2／2.1／2.2 AA標籤掃描未報違規。
- 長回答亦以320px、200%與間距覆寫實測：彈窗clientWidth/scrollWidth同為286px、回答保留兩段；Tab從回答移到下一個可用問題，axe掃描未報違規。
- 僅更新行銷遊戲的資料、對話呈現、相關測試與文件，未提交或部署。

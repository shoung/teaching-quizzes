# 第二章 PRD：客戶來訪，像偵探一樣做企劃

版本：0.5｜更新：2026-11-08｜狀態：已按使用者指定玩法重製，進行本機驗收。

本規格取代上一版常駐分頁工作臺。第二章必須延續第一章的角色移動、找人對話與中央彈窗；客戶來到辦公室，玩家透過訪談理解需求，再從大量選項辨認有證據支持的判斷。

## 1. 核心循環

走向客戶／G帶路／E互動 → 聽客戶逐句敘述 → 有限次追問 → 查看訪談筆記 → 左池拖到右池組成判斷 → 提交本輪 → 回到辦公室繼續下一輪 → 最後提出企劃 → 老闆評價與專家講評。

初始先顯示可走動的3D辦公室與來訪客戶，不自動開啟常駐工作臺。所有對話、推理與結算仍在正中央彈窗，開窗時場景暫停，關閉後繼續走動。第一章既有E直接互動入口保留，避免慢速裝置被尋路阻擋。

第二章一位客戶：虛構校園健身工作室「轉角動作室」的林老闆。五輪共用同一個委託，目標10–15分鐘。沒有倒數，玩家可慢慢讀、查名詞與討論；時長須在完整實作後另經試玩確認。

## 2. 五輪內容

| 輪次 | 客戶先描述的內容 | 玩家要判斷的內容 | 候選池 |
| --- | --- | --- | --- |
| 1 需求與痛點 | 公司現況、初訪者詢問、尖峰人力與服務問題 | 哪些顧客痛點有訪談證據，哪些只是猜測 | 20項 |
| 2 顧客樣貌 | 初訪者的行為、需求、顧慮與期待 | Persona的基本情境、需求、痛點與期待 | 至少16項 |
| 3 顧客旅程 | 使用前、使用中、使用後的接觸與交接 | 至少兩項痛點及兩項服務機會，能對應三階段 | 至少16項 |
| 4 服務方案 | 客戶資源限制與三份AI示範創意草稿 | 比較A/B/C，選一個本週先做的主方案及支持理由 | 至少16項 |
| 5 服務藍圖 | 方案如何交付、誰接待、誰支援與例外情況 | 顧客行動、前台、後台、支援系統及人工補救 | 至少16項 |

每輪多個正確項目，不做五道單選。整份提案由五輪判斷累積，而不是五個互不相干的小題目。

## 3. 訪談規則

- 每輪先有三段短敘述，接著提供八種不同面向的追問。
- 每輪最多問五個不同問題，五輪各自計數；問過的問題可以從筆記重讀。
- 重複問題不再扣次數，也不提供額外新線索。無效操作或快速連點不能變成第六問。
- 關窗、回世界、切章、回看前輪都不補額度；只有明確重新開始第二章，才重設第二章所有額度。
- 不要求問滿五次才推理。玩家可提早整理，若還有額度也能回來補問。
- 必要正確線索可在五次追問內取得，不設需要問八題才能答對的陷阱。
- 每次提問只顯示當下客戶回答，接著由玩家選擇繼續追問或開始整理；不一次鋪滿完整訪談逐字稿。

訪談筆記保留已聽的情境與已問回答。未問過的回答不在推理階段提前公開；結算解析可提供相關完整線索供學習。

## 4. 雙池推理操作

桌面中央視窗分為左側「線索池」及右側「我的判斷」。候選卡只呈現簡短內容，不揭露正確標記、分數或解釋。

- 可把左池卡片拖到右池，也可拖回左池取消。
- 每張卡另有加入／移回按鈕，鍵盤與手機不必依賴拖曳；同一項目不會重複加入。
- 手機改用上下排列或等價的池切換，不縮小整張表格。
- 移動卡片後提供簡短狀態提示，鍵盤焦點跟著移到該卡的新操作位置。
- 右池至少選一項才能提交；可在提交前自由改選。第四輪主方案卡互斥，選一張主方案及至少一張理由才能提交。
- 提示「只選已有線索支持的判斷，未驗證假設先留在線索池」。不以看似合理但無據的推測充當已確認事實。
- 現在只顯示選了幾項，不即時公布正確數或答案；最後結算才揭曉。

回看已提交前輪可保留答案。若修改並重新提交較早輪，先確認會清除後續提案答案；各輪已用追問次數仍保留，不藉重做退還。

## 5. 結算與評分

五輪提交後，提出提案即進入結算。未完成不能用網址跳到假結果。

每輪滿分20，五輪總分100。以本案有證據支持的參考項目判分：

本輪得分 = max(0, 四捨五入((正確命中數 − 錯選數) ÷ 本輪正確項目數 × 20))。

漏選不加分，錯選扣分，未選錯誤項目不另給分。重複ID不重複計算。全選不能拿高分。不同輪的參考項目數不同，仍各自正規化為20分。

| 評級 | 總分 | 老闆的整體反應方向 |
| --- | --- | --- |
| S | 90–100 | 高度契合，提出仍需微調或試行驗證之處 |
| A | 75–89 | 大致滿意，補齊遺漏與交接後再試行 |
| B | 60–74 | 方向可以討論，但還有重要缺口 |
| C | 40–59 | 與客戶情境有落差，需要修訂 |
| D | 0–39 | 暫不採用，回頭整理訪談與證據 |

評級、分數與評語都由實際選擇導出，不用固定假成績，不依提案文案長度或個人審美評分。

### 老闆角色

從林老闆的公司目標、資源限制與顧客問題看提案是否契合。評語引用玩家實際選中的正確方向、錯選或漏選，說明滿意或不滿意的原因，不只顯示一個分數。

### 行銷企劃專家角色

以世界級行銷企劃專家的分析風格，提供教學角色評語：哪一輪判斷較完整、哪些選擇有根據、哪些是誤判或遺漏，以及下一次該追問什麼。提供逐輪命中／錯選／漏選解析，能查看客戶原話支持的依據。

兩者均明示為虛構教學角色，不冒稱真人專家背書、真實客戶滿意度或即時AI判斷。這是本案提案契合度的課堂分數，不是工作能力診斷。合理但尚無證據的假設可在解析中說明，不把真實世界的創意簡化為只有一種正解。

結算先顯示老闆反應及評級，專家講評、五輪得分與逐輪解析按需切換／展開，保持字大與資訊簡潔。重新接案只清第二章，不動第一章。

## 6. 章節、音訊與隱私

- 所有已提供章節可任意開始，不需前章通關或達到分數。兩章在同一頁面的記憶體中各自保留進度。
- 沿用穩定入口 #/quiz/marketing-day/1，以及第二章既有hash路徑；刷新後清除本局，安全回到來訪開場。
- 同一OfficeScene、方向控制與角色互動，不把第二章做成另一套分頁表單。
- 同一音訊hook支援移動腳步、點擊、開關窗、拖放、提交與結案；開窗暫停移動聲，靜音與背景音樂可控。
- 無登入、無存檔、無後端、無個資蒐集。AI創意是有標示的劇本草稿，不呼叫即時AI或新增金鑰。
- 使用者原有繁體中文、大字、中央彈窗、手機／平板／桌面及鍵盤要求持續適用。

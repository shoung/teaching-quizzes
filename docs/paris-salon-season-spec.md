# 沙龍夫人的經營筆記：六場一季（已核准方向）

玩家扮演巴黎約 1900 年的新手克萊爾夫人，成功沙龍主路易斯擔任導師。保留所有現有人物、底圖、Logo、色彩、音效與音樂。每季六場，操作只有 NPC 對話及面板選擇，不加入移動或手機版本。

每場流程：閱讀市場與上一場回饋 → 設定主題、主受眾、規模 → 自由搭配有限準備行動 → 舉辦 → 查看財務、漏斗、體驗、熟客及口碑 → 下一場。資金、熟客、口碑、知名度、座位、培訓與環境投資跨場累積。收入與成本分列，零資金也可辦低成本聚會恢復。設施不能憑空創造需求，宣傳不保證到場，研究不直接加人氣。不能重複結算或第七場。

教學涵蓋 12 項：研究、主題受眾定位、參與式節目、藝術合作、助手培訓、臨時助手、座位投資、環境改善、訊息實驗、渠道宣傳、熟客會員經營、贊助。主題與受眾為每場基本配置，其餘 11 項為可組合行動。每項呈現理據、成本、時間及取捨，回顧連結實際結果與學科概念。不設正確答案或選項得分。季末顯示六場趨勢、持續資產及決策回顧；數值是簡化教學模型。

首兩場提供較完整導師指引，其後由玩家主動詢問。接待超載、需求不足、現金短缺有情境式提示。所有方案有成本、沒有通用最優答案。熟客留存清楚分母；宣傳漏斗層層區分；研究或小樣本實驗不能冒充因果證據。

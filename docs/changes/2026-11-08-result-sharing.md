# 顧問闖關成果分享

範圍僅限麥肯錫測驗結果底部的分享功能，原題目、計分與其他子站不變。使用者已要求實作並單獨推送。

- 「分享測驗結果」開啟可關閉的預覽，包含本次入場券插畫、分數、層級、六項技能的PNG，以及可編輯的貼文文字。
- 全程在瀏覽器生成，不上傳結果、不建立可公開還原答案的網址。貼文只附原有測驗介紹短網址。
- 按「分享到社群」把PNG檔案與文字交給系統分享面板，由使用者選擇App及發布；不同App對文字／圖片的接收方式可能不同。
- 不支援檔案分享或分享失敗時，仍可下載PNG、複製／選取貼文。取消分享不宣稱已發布，也不自動下載。
- 原生dialog、可見焦點、Escape／關閉還原焦點、大字與320px重排；生成失敗可重試，離開結果釋放預覽Blob URL。
- 驗證：PNG實際產生及下載、圖文分享payload、取消／不支援／失敗／重試、貼文不含答案、鍵盤與無障礙回歸；npm test與build後，只提交指定分享檔案至正式main並驗證Pages。

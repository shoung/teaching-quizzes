# 沙龍經營 v4：NPC 情報、卡牌與回合演出

依 2026-11-08 使用者的具體修改指示直接實作，延續既有桌面遊戲與美術；先交付本機試玩，未授權本輪自動更新正式站。

## 遊玩循環
1. 每回合場上為克萊爾與三位 NPC（露易斯夫人＋兩位輪替角色），位置、縱深、大小與朝向有差異；移除右側人物選單與角色移動。
2. 點人開啟底部 RPG 對話，只有說話者姓名、肖像及至多三行正文，不使用原本標題／市場消息段落。打字機逐字顯示，點擊或 Enter/Space 先補完、再下一句；每人有多句口語對話，非導師至少180字、導師至少300字，每句至多42字，以多頁承載。
3. 每回合至少完成一位在場非導師 NPC 的對話才可規劃；每回合只提供在場角色掌握的線索。已聽摘要存入帳冊，規劃頁不直接公開完整 market.news 或未聽過的提示。所有經營卡牌仍可使用，缺席者無法提供當日情報。
4. 場上常駐經營帳冊與沙龍計劃；左下只保留返回標題與設定。返回標題先確認並保留進度。分享只在標題頁。
5. 規劃順序為基本配置 → 卡牌選擇區 → 本場預估。全部11張牌橫向交疊，分類以顏色與標籤區分，不設篩選按鈕。滑鼠停留／鍵盤聚焦才展開內容；點牌放入上方選擇池，點已選牌退回。所有費用、時段、取捨仍可讀，超支／超時保留原因，不扣錯資源。
6. 「舉辦沙龍」是金色花紋的主要操作。先結算一次並儲存，再演出插圖＋進度條，然後展示回顧；重新整理不重複扣款／發收入。可略過演出，減少動態時縮短。
7. 結算明示資金、熟客、口碑、知名度、設施前後差與正負增減；提供來賓回饋、露易斯夫人與助手的情境建議，連回本次配置，形成PDCA。
8. 知名度初始50、範圍0–100。好表現能上升，接待失誤／失望與未服務需求能下降，宣傳不能保證抵銷壞體驗。重調觸及基準，不能因初始50造成首場必定嚴重超額。
9. 六場確認後先看露易斯夫人專屬結語，再看季報；結語狀態可還原。沒有第七場或逐題正解評分。

## 聲音與介面
修正固定衰減造成的低音量，測量錄音本身的音量，讓100%確實有正常可聽的音樂與音效，保留0音量、靜音、離頁暫停、首次手勢啟用。所有HUD參數可 hover/focus 顯示來源與影響的提示。卡牌與人物沿用象牙、墨綠、酒紅、金色與原PNG；維持桌面鍵盤、200%文字與減少動態支援。

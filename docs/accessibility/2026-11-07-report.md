# 全站無障礙與獨立測驗修正報告

- 日期：2026-11-07
- 基準：WCAG 2.2 AA；55 條國際準則對照及 5 項台灣補充檢查。
- 範圍：首頁、兩份測驗的全部 56 題、結果、展開解析、搜尋、錯誤頁與圖片放大。
- 檢查結果：38 項通過、19 項不適用、3 項需人工覆核，未留下已知自動掃描失敗項。
- 這是實作與測試報告，不宣稱無障礙標章或全面認證。

## 使用者要求與完成內容

1. 全站將可見小字提高至至少 1rem（預設 16px），內文 1.125rem（18px）。WCAG 並沒有固定最小字級；此為本案閱讀規則。
2. 加深輔助文字、控制邊界與圖表線條；保留照片原始色彩，不套濾鏡。
3. 首頁保留目錄；測驗題目、結果、頁首、頁尾及錯誤頁均無目錄入口／提示。每份測驗頁首 h1 使用自己的標題。
4. 雷達圖以圖形編號配合可重排 HTML 文字數值，不再依賴隨 SVG 縮小的微小文字。
5. 使用原生選項名稱、放大對話框、略過連結、路由焦點及搜尋／複製狀態播報。

## Runtime 覆蓋

- 16 種頁面／互動狀態，axe A／AA 標籤違規總數 0。
- 56 道實際渲染題目，字級、對比、目標尺寸、重排與目錄連結皆無回歸。
- 10 組 320px 縮放／文字間距案例，無頁面溢出或元素水平裁切。
- 圖片 modal：背景按鈕無法取得焦點，Escape 還原放大按鈕。Tab 過程觀察到 BUTTON → BODY → DIALOG；BODY 是瀏覽器介面焦點參與，未把背景控制視為可操作，也未宣稱每個 Tab 都停在 modal 內控制。
- 另行驗證圖片 modal 的 axe 掃描，以及搜尋框、選項、分享與放大按鈕的預設／hover／focus 邊界對比，見 `controls-runtime.json`。
- 原生對話框與焦點外框以 DOM、鍵盤、樣式及區域量測覆核；未完成 VoiceOver/NVDA 實際朗讀與逐像素視覺認證。

## 證據與重跑

- `baseline-runtime.json`：修正前實測；`after-runtime.json`：最終各狀態掃描。
- `all-questions-runtime.json`：全部 56 題；`resize-runtime.json`：文字放大與間距。
- `keyboard-runtime.json`、`dialog-runtime.json`：鍵盤、原生 modal 與焦點記錄。前者的 `inside:false` 需搭配後者的背景阻擋及 BODY 說明閱讀。
- 共用量測在 `scripts/a11y/inspect-page.mjs`；全流程在 `scripts/a11y/full-audit.ego.mjs`。
- 獨立唯讀程式碼審查無阻擋問題；其英文語系及 modal 證據表述建議已處理。

## 依據

- [W3C 1.4.3 文字對比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：一般文字 4.5:1，大字 3:1，依各項例外判讀。
- [W3C 1.4.4 文字放大](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)：可放大 200% 不遺失內容或功能。
- [W3C 1.4.10 重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：320 CSS px 垂直內容避免雙向捲動。
- [W3C 2.5.8 目標尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：24×24 CSS px 或符合例外；本案主要控制額外採 44px。

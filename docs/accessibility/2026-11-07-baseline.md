## 已授權修正方向
1. 字體改相對單位，放大小字；從 CSS 定義層修正輔助色、控制邊界與圖表標籤。
2. 首頁保留目錄；測驗與結果使用專屬標題頁首，移除所有目錄、首頁品牌連結及返回目錄提示。
3. 使用原生表單標籤、對話框及焦點機制，修正選項名稱，補上搜尋播報與圖表文字資料。
4. 以 axe-core、計算樣式、320px／200%／文字間距與鍵盤實測修復後驗證。

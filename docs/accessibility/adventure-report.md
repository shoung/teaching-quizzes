## 本次驗證證據與限制

- `adventure-runtime.json`：乾淨正式建置，20 狀態，含兩份介紹的桌機與320px、作答、結果、展開解析與錯誤頁；axe及字級、對比、控制尺寸、頁面溢出皆無失敗。
- `adventure-questions-runtime.json`：實際點選全部56題；兩份測驗滿分結果正確，所有子頁首頁連結為0。
- `adventure-resize.json`：11組320px下的200%文字放大／自訂間距；預設最小16px，200%最小32px，無頁面橫向溢出或文字對比失敗。包含平均數、截斷座標及樣本圖解。
- `adventure-keyboard.json`：第一次Tab到略過連結，3px焦點框位於視窗內；Enter進main；開始後聚焦題目；方向鍵選答案、下一頁與上一頁均有效且保留選取。
- 原始色彩照片與色卡不變。生成插畫為裝飾／敘事，不含題目數字；8組圖解以真實HTML文字提供相同數據，放大後可重排。
- 唯讀程式碼審查發現第7題部分給分理由不準確，已修正為方向正確但未算差額的選項；修正後48項測試及正式建置通過。

# 沙龍夫人的經營筆記・桌面可玩版實作計畫

> **For agentic workers:** 使用已核准桌面 UI 與共享型別，各分工只編輯指定檔案。使用者已授權功能開發，直接完成測試、整合與試玩；不等待再次核准計畫。

**Goal:** 讓使用者在電腦上實際完成四幕十二個決策、移動、保存、計分與結果。
**Architecture:** 題目、確定性規則、React 桌面 UI 分離。答案歷史是衍生數值的唯一來源；第九題後鎖定活動開場資料；型別統一定義在 `src/types.ts`。沿用已核准人物、場景及配色，以獨立樣式範圍保護其他測驗。
**Tech Stack:** 現有 React、TypeScript、Vite、Vitest、axe、QRCode；不加套件。
**Spec:** `docs/paris-salon-prd.md`，加本輪桌面 UI 通過與只驗收桌面的新指示。

## Global Constraints
- 純前端、繁體中文、無登入／個資／後端、無 API AI。
- 十二題、六面向各兩題、每題 0–3、總分 36；經營成果與教學分數分離。
- 初始 B100/A10/T50/Q40/R0/W0；容量 36；第九題後以 PRD 公式鎖定到場。
- `#/quiz/paris-salon/1` 介紹，`#/quiz/paris-salon/play/<題號>` 答題，`#/quiz/paris-salon/result` 結果。
- 本機獨立版本鍵 `learning-lab:quiz:paris-salon:v1`，損壞與儲存失敗安全處理。
- 桌面驗收；保留鍵盤、可讀字級、文字放大與對比，不擴充手機玩法。
- 不修改第三個遊戲、不覆蓋其他工作、不部署或推送。

## Review Focus

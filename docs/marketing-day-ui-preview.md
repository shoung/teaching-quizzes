# 行銷人的一天 第一階段畫面預覽

日期：2026-11-07。狀態：畫面已核准。本文件保留第一階段紀錄，完整遊戲見[試玩說明](./marketing-day-playtest.md)。規格依據：[已核准 PRD](./marketing-day-prd.md)。

## 預覽方式

本機開發伺服器：`http://127.0.0.1:5174/#/quiz/marketing-day/1`。

重新啟動可執行 `npm run dev`，改用終端顯示的埠號。主頁第三個「行銷人的一天」卡片也提供預覽入口。尚未部署到正式網站。

點「開始上班」查看辦公室，再點「與美玲對話」查看人物對話與中央決策。右下角「審稿」可直接切換入口、辦公室、對話、決策、回饋、圖鑑、結案、載入與文字備援；「六個決策樣稿」分頁可檢查不同文字長度。

## 這次完成

- 實際 WebGL 3D 辦公室，採低多邊形桌椅、設備、植物與方塊人物，使用斜俯視鏡頭、光影與少量角色標籤。
- 精簡 HUD：上方時間與工具、下方當前任務與主要互動，避免把遊戲做成網站儀表板。
- 中央模態決策面板，包含 32px 桌面標題、18px 內文及選項、16px 輔助字、未選／選中／確認狀態，以及可展開的任務資料與術語。
- 人物對話、名詞圖鑑、固定結案樣式與手機版。
- 原生模態視窗搭配明確的 Tab 循環、Escape 收合與啟動控制焦點返回。
- WebGL／3D 模組無法載入時保留文字互動；預覽模組載入失敗時提供重新整理操作。

## 尚未啟用

沒有遊戲狀態機、正式移動／自動尋路、答題進度、後果推演、計分、存檔、短網址服務或正式 QR code。單選、開關面板、術語展開與樣稿切換僅用於介面審核。結案的 75 分及三面向數值是固定示例，不是根據選擇產生的成績。

## 驗證紀錄

- `npm test`：7 個測試檔、48 個測試通過。
- `npm run build`：型別檢查及 Vite 正式建置通過；3D 依賴獨立延遲載入。Three.js 場景 chunk 約 541 kB（gzip 約 136 kB），建置會提示大 chunk。
- Ego Lite 實際顯示 3D Canvas；參考站 Canvas 亦已擷取，作為方塊人物與斜俯視風格比對依據。
- 桌面五個主要面板：對話、決策、回饋、圖鑑與結案均量測置中，無水平溢出，這次 axe WCAG A／AA 掃描未發現違規。
- 390px × 844px：決策面板無水平溢出，選項與確認操作可見。
- 320px × 740px、根字級 200%、文字間距覆寫：決策內容垂直捲動、無水平溢出，HUD 分列後工具仍位於視窗內。
- Tab 及 Shift+Tab 連續循環保持在面板內；Escape 後返回啟動控制，直接對話流程可返回場景互動按鈕。
- 透過本機請求阻擋分別模擬 3D 模組與預覽模組載入失敗，兩種中文錯誤備援皆顯示。
- 獨立程式審查指出的延遲載入錯誤邊界與大字 HUD 裁切已修正，陰影資源清理與圖鑑分類選取亦補齊。

自動掃描與尺寸量測不等於完整 WCAG 認證。這輪交付的是畫面樣稿，正式遊戲流程與十分鐘時長仍待第二階段實作及試玩。

Ego Lite 整頁截圖仍會逾時；介面檢視圖由當前 DOM、樣式與真實 3D Canvas 在瀏覽器中合成，不宣稱為原生整頁截圖。實際操作以本機預覽為準。

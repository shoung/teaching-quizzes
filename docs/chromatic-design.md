# 色彩天賦測驗教學版

## 使用者新增需求
復刻指定範例的測驗內容與照片；大字、大圖，美術設計更完整；每份測驗獨立網址與進度；移除姓名與 Email，只保留測試題；完整結果由實作者補上。

## 來源觀察
原站 35 個步驟包括 2 個個資欄位、28 道題目與段落過場。實際題目包含 26 道單選與 2 道複選（第 7、21 題）。公開載入資料包含每個選項的參考權重，部分題目為主觀偏好。共 68 個不同圖片來源，包含封面。未送出原站表單。

## 設計與規則
- 保留題目、原始選項順序與原始圖片檔案，將簡體選項轉成繁體。
- 使用米白底、深綠導覽與低彩度輔色；桌面題目 30px、手機 25px，照片 2 欄完整比例顯示，放大時使用原始圖片。
- 移除個資欄位與行銷解鎖，進入連結直接顯示第一題。
- 使用 `#/quiz/chromatic-intuition/1` 作為固定分享連結。獨立 localStorage 鍵與版本化進度，寫入只影響當前測驗。
- 保留前後頁、複選取消、答案保存、鍵盤焦點與原生放大對話框。
- 自行設計教學結果：15 道參考題的等權吻合率、13 道主觀感受紀錄、四面向回饋、較低面向的具體練習、逐題解析與列印。
- 色彩心理與審美感受依選擇記錄，不計對錯，不宣稱常模排名；報告清楚交代教學版評分方法與螢幕影響。

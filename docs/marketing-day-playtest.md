## 試玩入口

[本機試玩](http://127.0.0.1:5174/#/quiz/marketing-day/1)。也可從主頁第三個「行銷人的一天」入口按「開始上班」。本輪未發布正式網站。

若需要重新啟動，執行 `npm run dev`，使用終端顯示的埠號與 `#/quiz/marketing-day/1`。

點「開始上班」，按紅色互動按鈕或 E 可直接與當前同事對話，不必等待角色走到。可以使用 WASD、方向鍵、手機方向控制或點地板走動；G／帶我去保留自動帶路。所有決策均在中央彈窗完成。

## 完整內容

一章六件事：上午對齊 TA／KPI、查看點擊與預購、查證 AI 文案；下午安排 A/B 測試、判斷小樣本預算，最後交付結案建議。每個選項都有自己的同事回應、工作後續與教學解析，不會因分數低而卡關。

TA、KPI、CTR、CVR、Landing Page、USP、CTA、A/B Test、UTM 與 ROAS 都可在對話或題目點開，右上角圖鑑可集中查閱。查名詞不會提交或清除選擇。

結案包含實際分數、最高參考分題數、三面向雷達圖與可讀分數表、六題回顧、兩個練習方向與重玩。逐題回顧與計分細節採展開閱讀，保持第一眼簡潔。

六題各 0–2 分，共 12 分後換算為 100。策略與實驗、數據判讀、查證與協作各兩題，分別依自身滿分 4 分正規化。這是課堂情境參考，不是工作能力診斷、錄取機率或實際績效預測。

## 進度與回看

- 未選擇不能確認，未作答不能跳題，未完結不能直接進入結果。
- 收合中央視窗只暫停當前互動，草稿留在這次頁面中；可按「繼續目前決策／回饋」再開啟。
- 上一頁保留答案。更改早題前先確認；取消則保留原選擇與後題，確認後清除後續答案與結案，從該題重新推演。
- 不登入、不存檔，不寫入本遊戲 localStorage、sessionStorage、Cookie、IndexedDB 或後端。重新整理、關閉或新開分頁後從介紹頁重新開始。
- 重玩清空這次六題與場景，不改寫其他測驗進度。
- WebGL 或 3D 模組載入失敗時，仍可用同一套 HTML 對話與決策完成六題與結果。

## 8-bit 音訊增補驗收

本輪由三位 Luna 子代理分別實作音訊引擎、搜尋配樂及整合介面，根代理審查與實測；實作後另由 Luna 扮演資深遊戲設計總監審查。

- 點擊、選項、展開／收合、返回、確認、抵達、結案與行走使用不同的 Web Audio 方波、三角波或量化雜訊提示；腳步以約 210ms 節拍播放，避免每影格疊音。
- 配樂為 Louswan 的錄音作品 `Overworld Theme`，來源、CC0 授權與檔案雜湊見 [音樂來源](marketing-day-audio-sources.md)。本機 MP3 約 33.1 秒循環，不在學生載入時從外站抓取素材。
- Ego Lite 實測：首次操作前未建立 AudioContext 或播放音樂；操作後 context 為 running，本機 MP3 的播放時間持續增加，loop 為 true。
- 音樂預設音量 25%，開中央彈窗時降為 14.5%；獨立音樂開關會暫停配樂。全域靜音會立即暫停配樂並設為零音量，取消靜音後恢復設定值。
- 操作說明內提供獨立音樂／音效音量與來源連結。320px、200% 文字及文字間距覆寫時，說明視窗寬度與捲動寬度同為 278px，頁面寬度 320px，手機靜音按鈕仍可見。
- 音訊設定彈窗的 axe WCAG A／AA 掃描為零違規；鍵盤連按兩次音量增加鍵，音樂值由 0.25 變為 0.27。
- 自動測試涵蓋音訊解鎖與重試、靜音、節流、移動／彈窗狀態、頁面隱藏、清理與 UI 事件去重。瀏覽器播放狀態的驗證不等同人耳聆聽驗收；最終音量平衡與長時間循環感受仍請試玩者確認。
- 分頁回到前景時會重啟未完的尋路；靜態陰影只建立一次，保留玩家接收陰影並減少行走繪製負擔。慢速環境的 G 導引抵達時間仍需在一般設備續驗，不列為本次已通過項目；紅按鈕／E 已改為直接互動並由總監代理完成六題，主線不受尋路影響。
- [總監代理審查](marketing-day-director-review.md)：實際六題選擇得到 67 分（8／12），面向為 100／50／50；圖鑑與六題結果回顧一致。可交付本地試玩；真人學生滿意度與實際完成時間仍待課堂驗收。

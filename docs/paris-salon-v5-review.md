# 沙龍 v5：助手分工、華爾茲與說明文案

本輪依使用者回饋完成；只改沙龍遊戲，保留人物、配色、場景和六場經營循環。

## 助手分工

舊版本固定每場 4 時段，單張卡為 1–2 時段，無升級管道。新版完全移除該參數，改用會成長的人手：

| 項目 | 規則 |
| --- | --- |
| 起始固定助手 | 2 人，含艾米爾及一位助手 |
| 一般準備卡 | 需 1–2 人；每位助手本場只分配到一張卡，準備後一起接待來賓 |
| 增聘固定助手 | 22 點含本季報酬，一次支付；立即加 1 人、上限 6 人，留到季末，每人增加 4 人舒適接待量 |
| 臨時助手 | 10 點，本場加 2 人，保留本場舒適接待量加 10 人效果；下場離開 |
| 聘用手續 | 克萊爾辦理，不占助手；兩張聘用卡各每場一次 |
| 培訓 | 技能等級，從下場起每級增加 3 人舒適接待量，維持原人數 |
| 金錢 | 卡牌報酬與聚會基本支出仍須在開場前付得起，收入散場入帳 |

固定助手報酬採季內一次付清，避免另加每回合必付成本，使零資金的小聚恢復路線失效。兩種聘用方式可依剩餘場次和工作量取捨；沒有另外塞入固定卡牌數或行動點限制。

新增第 12 張增聘卡；HUD、卡牌池、預估、帳冊與結算都顯示相同人手數字。收回增加人手的卡若會留下超額分工，會保留原計劃並提示先收回其他工作。

存檔改用 `learning-lab:quiz:paris-salon:v5`；原 v4 鍵保留，避免以新版規則重算舊決策。

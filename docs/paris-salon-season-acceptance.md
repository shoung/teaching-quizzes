# 六場經營模擬驗收清單

此清單驗證 v3；舊 v2 的品質檢查不作為新玩法的通過依據。

## 真正的經營循環
- [x] 進場先認識新手克萊爾與導師路易斯，知道每季六場。
- [x] 同一場能自由搭配多項準備，能檢查時間與資金，不是逐題作答。
- [x] 配置前可看研究情報、主題受眾的需求、規模與接待上限。
- [x] 舉辦後分清宣傳觸及、詢問、預約、到場與候補。
- [x] 收入與成本對帳；下一場沿用現金、熟客、口碑、知名度與設施。
- [x] 第六場後可讀整季趨勢與自己實際做過的決策，不出現正解數或分數。

## 教學因果與平衡
- [x] 研究改善情報而非直接加人氣；小實驗沒有統計顯著假宣稱。
- [x] 主題與受眾契合影響體驗，不把某一受眾設成唯一正解。
- [x] 宣傳有需求效應但不保證到場與口碑；過載會傷害體驗。
- [x] 訓練／設施永久，臨時人手與節目為本場，成本時間不混用。
- [x] 擴座不能取代人手、沒有需求時座位閒置；有限季數影響投資回收。
- [x] CRM 依實際體驗與意願，留存率採正確分母。
- [x] 至少兩種不同策略能完成六場並取得不同合理成果。
- [x] 錢不足時仍可回復，不靠強制免費現金或負值透支作弊。

## 技術與桌面可玩性
- [x] 重複點擊舉辦、還原和重新整理不重複結算。
- [x] 草稿與未讀結算保留；未來／錯誤網址不能跳過六場。
- [x] v2／損壞進度安全處理，重玩只影響 v3，儲存不可用仍可完成。
- [x] Logo、近景背景、3–4 頭身人物、金色紙張彈窗、音樂與音效保留。
- [x] 鍵盤進場、面板焦點循環、Escape 關閉與焦點返回可用。
- [x] 1440×900、1280×720、200% 文字下沒有遺失選項、費用與主要操作。
- [x] npm test、npm run build、git diff --check，獨立資深遊戲企劃總監檢查。

驗收依據：178 項專案測試、build、Ego Lite 完整六場原生流程、兩種純引擎策略、總監原生前兩場試玩、需求／入場／候補重現案例，以及各面板 axe 與桌面文字放大驗證。通過屬本機教學試玩驗收，非公開部署或正式學習成效研究。

# 教學測驗集設計

## 需求
教學用測驗平台：首頁為目錄，每份測驗有子頁，每頁一題，回答後按下一頁，最後直接顯示前端結果。

## 本次實作選擇
- React + TypeScript + Vite：可擴充共用元件與型別化題庫；相較純 HTML 多頁，重複較少；相較需要伺服器的全端框架，可完整靜態部署到 GitHub Pages。此選擇由實作者依本次框架需求決定。
- 名稱「學習小測所」，繁體中文，米白、深綠與橘色的輕盈教學介面。
- 首頁主題卡片、搜尋及分類，三份示範題庫；答題頁保留進度，結果頁給分並列出解析。
- Hash 子路由：首頁 `#/`，題目 `#/quiz/<id>/<1-based-index>`，結果 `#/quiz/<id>/result`。
- localStorage 僅存本瀏覽器的答案與題庫版本，讀寫失敗仍可用；版本變更自動淘汰舊進度。
- 只提供單選題；本次不需要登入、伺服器、排行榜與個資蒐集。
- GitHub Actions 在測試與建置成功後部署 `dist`。

## 驗收
未選答案不能前進；上一頁保留答案；答案不在完成前揭露；分數正確；重測清除答案；破損進度與無效網址可恢復；手機與鍵盤可操作；公開儲存庫與 Pages 網站實際可用。
